Account & Login

How to register, login, and reset password

How do I register a new account?
  1. Click Register on the login page
  2. Enter your First Name, Last Name, Email
  3. Create a Password (minimum 8 characters)
  4. Click Create Account
  5. Check your email for a 6-digit OTP code
  6. Enter the code to verify your email
  7. That's it! You're now logged in.
How do I login?
  1. Go to the Login page
  2. Enter your Email and Password
  3. Click Sign In
  4. If enabled, enter the OTP code from your email
  5. You'll be redirected to the Dashboard
Tip: Enable Two-Factor Authentication in Settings for extra security!
How do I reset my password?
  1. Go to Login page
  2. Click "Forgot Password?"
  3. Enter your email address
  4. Check email for reset link
  5. Click the link and create a new password
  6. Login with your new password
How do I enable Two-Factor Authentication?
  1. Click your profile name in top-right corner
  2. Go to Settings
  3. Find "Two-Factor Authentication"
  4. Click "Configure"
  5. Enter your phone number
  6. Verify with OTP and you're protected!

Common Issues

Solutions to frequent problems

OTP Code Not Received

Email may take a few minutes. Check spam folder. Codes expire after 10 minutes.

Use password login or request new code
Import Failed

File may be corrupted or in wrong format. Ensure UTF-8 encoding.

Save as .xlsx or .csv with UTF-8 encoding
Social Post Failed

Access token may have expired. Social platforms require periodic token refresh.

Reconnect social account in settings
Charts Not Loading

JavaScript may be disabled or blocked. Charts require Chart.js library.

Enable JS and refresh page
Image Upload Failed

File size may be too large or format not supported.

Use JPG/PNG under 5MB
Login Failed

Email or password incorrect. Check caps lock and try again.

Reset password via OTP or contact admin
